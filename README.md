
# Employee Self-Service Training Portal

## Project Overview
A Pega-based Employee Self-Service application for managing employee training requests.

## Main Workflow
1. Create Training Request
2. Enter Training Details
3. Select Preferred Dates
4. Eligibility Review
5. Manager Approval
6. Enrollment Processing
7. Completion

## Key Features
- Employee training request submission
- Training date and location selection
- Eligibility review
- Manager approval and rejection flow
- Enrollment processing
- Training completion tracking

## Technology
- Pega Platform
- Pega App Studio
