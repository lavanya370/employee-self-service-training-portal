# Employee Self-Service Training Portal

## 📌 Project Overview

The Employee Self-Service Training Portal is a Pega-based application designed to simplify and manage employee training requests.

The application allows employees to submit training requests, provide training details, select preferred dates, undergo eligibility review, receive manager approval, and complete the enrollment process.

## 🎯 Objective

The main objective of this project is to provide a structured and automated workflow for managing employee training and development requests.

It reduces manual processing and provides a clear workflow from training request submission to completion.

## 🔄 Application Workflow

The training request follows these major stages:

1. Create Training Request
2. Enter Training Details
3. Select Preferred Dates
4. Eligibility Review
5. Manager Approval
6. Enrollment Processing
7. Completion

## ✨ Key Features

- Employee training request submission
- Training course selection
- Employee justification and comments
- Preferred training date selection
- Training location selection
- Eligibility review
- Manager approval and rejection
- Enrollment processing
- Training completion tracking

## 👤 User Roles

### Employee
- Creates training requests
- Enters training information
- Selects preferred dates
- Tracks request progress

### Manager
- Reviews employee training requests
- Approves or rejects requests
- Provides decision during the approval stage

## 🛠️ Technology Used
